# SPS2 Setup Assistant 1.2.0

VRCFuryでSPS3が公開され、従来のSPS2 Setup Assistant 1.1.1ではアバターのビルドが止まる問題が確認されています。SPS3への正式対応バージョンとなるv2.0.0は開発中のため、まずはこのビルド停止への対処を先行して届ける暫定正式バージョンとして、1.2.0を公開します。

1.2.0-beta.5をベースに、VRChat SDK 3.10.6に対応するため、NDMF Installerが導入するSPS for NDMFを1.1436.0に更新しました。SPS3への正式対応は、今後のv2.0.0で行う予定です。

## 既知の制限

- **「後方互換性」をOFFにしても反映されないことがあります。**
  VRCFuryでは、OFFにしても古い方式向けのメニューや互換用の仕組みがアバターに残る問題があります。このバージョンでは修正していません。
- **VRCFuryからSPS for NDMFへの切り替えが止まることがあります。**
  すでにセットアップしたアバターで使用する方式を切り替えると、設定の確認中に停止する場合があります。Installerを入れ替えるだけでは、既存のセットアップは自動変換されません。
- **NDMFで同じ名前の部位を複数使っている場合、名前と保存済み状態に注意してください。**
  重複を区別する番号の付け方が変わり、メニューや外部連携で使う名前が変わります。外部ツールと連携している場合は、その設定を見直してください。VRChatで保存していた各部位のON/OFF状態が引き継がれない可能性もあります。

更新前にプロジェクト全体をバックアップしてください。更新後は設定とメニューを確認し、アバターを再ビルド・再アップロードして、各部位の動作を確認してください。

SPS2 Setup Assistant 1.2.0 系列別 VPM インストーラー

1.2.0 向けです。共通 SPS2 と依存は公式配布元から取得します。
Fury / NDMF のどちらか一つの ZIP を選び、unitypackage を対象 Unity 2022.3
VRChat Avatar プロジェクトにインポートし、VPAI の確認画面を読んでください。
依存本体・アバター・scene は同梱しません。通信と公式配布からの取得が必要です。

Furyバージョン: 共通SPS2 1.2.0 + VRCFury >=1.0.0 + lilToon >=1.0.0。
NDMFバージョン: 共通SPS2 1.2.0 + SPS for NDMF 1.1436.0 + MA >=1.18.1 <2.0.0
       + NDMF >=1.11.0 <2.0.0 + lilToon >=1.0.0。Fury/Stub/Migratorは要求しません。
SDKは共通SPS2のVPM必須依存 >=3.10.4 <4.0.0 として解決されます。
表示用lilToonを両インストーラーの取得対象に含めます。

Unity: Tools > LumaKroma > SPS2 Setup Assistant を開きます。
使える系列が一つなら新規生成で自動選択され、両方あれば希望の系列を選べます。
インストーラーは保存済み設定・生成物の系列を書き換えません。
既存依存は指定範囲に応じて解決されるため、バージョンの更新が提案される場合があります。
両インストーラーは同じVPAI一時GUIDを使うため同時にインポートしないでください。

導入前にプロジェクト全体を外部へバックアップしてください。
旧Assetsバージョンの Assets/LumaKroma/SPS2SetupAssistant は標準VPM移行で削除対象となり、
中のユーザー追加ファイルも対象になり得ます。先にフォルダを確認してください。
Assets/SPS2Settings はその削除対象ではありません。既に導入済みの場合の早期終了は
重複した旧Assetsバージョンを後から片付ける保証にはなりません。

更新後は各SPS基盤の標準メニュー・初期値・保存設定を使用します。
Local Onlyは基盤側のStealth Modeを使用し、メニュー言語はソケット名のみに適用されます。
既存の表示名を反映するには「置き換えずに変更を反映」を実行して保存してください。
アバターの再ビルド・再アップロード後に、メニューと各モードの状態を確認してください。
NDMFのObjectアクションを使う場合は参照先とON/OFFの指定も確認してください。
このインストーラーは公開されたVPM listingから取得します。
