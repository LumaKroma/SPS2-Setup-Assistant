# SPS2 Setup Assistant

VRChatアバターへのSPS2セットアップを補助するUnity Editorツール

使用する部位を選ぶだけでソケットの配置やメニューの生成をまとめて行えます。

## 導入

### [▶ VCC / ALCOMに追加](https://lumakroma.github.io/SPS2-Setup-Assistant/)

上のリンクから追加ページを開き、VCCまたはALCOMでリポジトリの追加を承認してください。

続いて導入先のアバタープロジェクトを開き、パッケージ一覧から **SPS2 Setup Assistant** を追加してください。

手動で追加する場合のリポジトリURL：`https://lumakroma.github.io/SPS2-Setup-Assistant/index.json`

## 使い方

### v1.1.0 開発中：言語とメニュー表示名

「画面の言語」と、アバターに保存する「メニューの言語」を別々に選択できます。
日本語・英語・韓国語・中国語（簡体字／繁体字）に対応します。
部位ごとの「メニュー表示名」は空欄で標準名を使用し、入力した名前は言語や
プリセットを変えても保持します。「標準名に戻す」で個別名を解除できます。
変更後は「置き換えずに変更を反映」または再生成で保存してください。
生成メニューの名前はこの画面で設定します。Socket側の `Name in menu` の編集は
最終表示名として使われません。既存設定のメニュー言語は日本語を維持します。
この版はUnity・実機確認前で、まだ公開リリースではありません。

一番シンプルな方法は、上部メニュー欄から `Tools > LumaKroma > SPS2 Setup Assistant` を開いて対象アバターを指定 → `プレハブを生成`。

生成前にプリセットや使用する部位、深度アクション、設定項目をカスタマイズできます。

設定の変更・再生成、テストプラグの配置もできます。

対象はHumanoidアバターのみです。自動配置の結果はアバターによって異なるため、生成後に位置や向きを確認してください。

## 機能

- プリセットを使ったセットアップ
- 使用する部位に応じたソケットの自動配置
- ソケットを操作するメニューの自動生成
- 深度アクションの設定
- 口と肛門をつなぐ貫通経路の生成
- Auto Mode・後方互換性・Local Onlyの設定
- 手動調整した位置を維持した設定の反映
- 設定に合わせた再生成
- 通常のテストプラグと、貫通確認用の長いテストプラグの配置

## 依存

- Unity 2022.3
- VRChat Avatars SDK
- VRCFury
- lilToon（テストプラグの表示用）
- Modular Avatar（任意・追従方式の追加）

## 従来のAssets版からの移行

1.1.0ではVPMの旧版移行機能を使い、導入時に旧 `Assets/LumaKroma/SPS2SetupAssistant` フォルダーを削除対象にします。移動済みの旧フォルダーもGUIDで検出される場合があります。設定保存先 `Assets/SPS2Settings` は削除対象に含めません。

**移行前にUnityを終了し、プロジェクト全体をプロジェクト外へバックアップしてください。** 旧フォルダー内へ追加したファイルや編集した内容も削除対象です。必要な内容を確認・退避してから進めてください。この機能による自動バックアップや、ごみ箱からの復旧は保証されません。

VPMインストーラーでは、表示される削除対象を確認してからInstallを選んでください。対象が想定と異なる場合や内容を確認できない場合はCancelしてください。VCC/ALCOM経由でも同じ旧版削除情報が使われるため、先にバックアップと内容確認が必要です。

導入後はコンパイルと保存済み設定・シーン・プレハブの参照を確認してください。問題があればUnityを終了し、移行前のバックアップから復元してください。VPM版を導入済みの場合、インストーラーが「Nothing TO DO」で終了して旧版が残ることがあります。再インポートで必ず重複を解消できるわけではありません。
