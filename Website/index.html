SPS2 Setup Assistant

VRChatアバターへのSPS2セットアップを補助するUnity Editorツール

安定版：1.1.1 ／ 系列選択対応：1.2.0-beta.1
NDMF 系列では VCC / ALCOM でプレリリースを表示して beta を選んでください。

使う SPS 系列を選択

「リポジトリを登録」ボタンは配布元の登録画面を開きます。パッケージの導入は、登録を承認した後に VCC / ALCOM の対象プロジェクトで行ってください。

1. VRCFury の配布元を登録

VRCFury リポジトリを登録

VRCFury 公式導入案内
https://vcc.vrcfury.com/

2. 対象プロジェクトに依存を導入

VRChat Avatar SDK のある Unity 2022.3 プロジェクトに VRCFury を導入してください。Modular Avatar はこの系列では任意です。

1. SPS for NDMF と MA / NDMF の配布元を登録

SPS for NDMF リポジトリを登録 MA / NDMF リポジトリを登録

SPS for NDMF 公式導入案内
https://spsndmf.vpm.nrzk.net/index.json
https://vpm.nadena.dev/vpm.json

2. 対象プロジェクトに依存を導入

VRChat Avatar SDK のある Unity 2022.3 プロジェクトに SPS for NDMF 1.1430.0、Modular Avatar 1.18.1 以上・2 未満、NDMF 1.11 以上・2 未満を導入してください。新規セットアップに Fury 本体・VRCFury Stub・Migrator は不要です。

3. SPS2 Setup Assistant を導入

SPS2 リポジトリを登録

登録を承認し、同じ対象プロジェクトに SPS2 Setup Assistant を導入してください。beta は 1.2.0-beta.1 を明示的に選びます。

https://lumakroma.github.io/SPS2-Setup-Assistant/index.json

Unity の Tools > LumaKroma > SPS2 Setup Assistant を開いて新規生成します。使える系列が一つなら自動選択されます。両方あれば希望の系列を選んでください。保存済み・生成済み設定は元の系列を保持します。

テストプラグの表示：lilToon

IcePop テストプラグを表示する場合は lilToon を別途導入してください。

lilToon リポジトリを登録

https://lilxyzw.github.io/vpm-repos/vpm.json

unitypackage から導入する場合

系列別インストーラーが、共通の SPS2 beta と選んだ系列の依存、表示用 lilToon を公式配布から取得します。依存本体は同梱しません。対象プロジェクトをバックアップしてから一つをインポートし、確認画面を読んでください。通信が必要です。

Fury 向けインストーラー ZIP NDMF 向けインストーラー ZIP

ZIP 内の unitypackage を使用します。既存依存は指定範囲に応じて解決されます。両方を使う必要はありません。旧 Assets 版からの移行は README の削除範囲を確認してください。

各依存のライセンスは SPS2 の MIT とは別です。SPS for NDMF を商用アバター制作・販売・寄付付きサービス等に使う場合は、改変版への依存・利用案内条件を確認してください。SPS for NDMF のライセンス
