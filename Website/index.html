SPS2 Setup Assistant

VCC／ALCOMで導入

unitypackageで一括導入

VCC または ALCOM で用意した Unity アバタープロジェクトに導入できます。使う基盤ツールに合った Installer ZIP を選んでください。

VRCFury用 Installer ZIP をダウンロード Modular Avatar／NDMF用 Installer ZIP をダウンロード

ZIP を展開し、中の unitypackage を対象プロジェクトの Unity にインポートしてください。Unity 内の Installer 確認画面で、SPS2 Setup Assistant 1.2.0-beta.1 と lilToon・選んだ基盤の依存パッケージを一括導入します。

依存パッケージのプレリリース版が選ばれる場合があります。確認画面でバージョンを確認してください。
