# 1.2.0-beta.3 — 指わっかの仮配置と警告

自動計算した指ポーズの推定指先間隔が目安を超えても、残る形状・校正チェックを通れば仮配置し、左右の部位名付きで実際のポーズでの調整を案内します。形状や骨参照が不正な場合は停止します。保存済み校正・手動位置・向き・scale を自動で置き換えません。
