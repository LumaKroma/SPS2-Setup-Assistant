生成済みセットアップの VRCFury／SPS for NDMF を切り替えられるようになりました。

**変更内容**
- 生成済み設定の基盤切替に対応
- 配置・校正・共通設定、追加したオブジェクトを保持
- 元の基盤や所有情報が欠けている場合は変更せず、再導入または手動削除して新規生成する案内を表示

切替前に両方の基盤と依存パッケージを導入してください。他の設定変更は切替とは別に適用します。

**導入方法**
VCC/ALCOMではプレリリースを表示し、1.2.0-beta.2を選択してください。
unitypackageから導入する場合は、使用する基盤に合わせてInstaller ZIPをダウンロードし、中のunitypackageをインポートしてください。
[導入ページ](https://lumakroma.github.io/SPS2-Setup-Assistant/)

**注意事項**
- beta版です。導入前にプロジェクトをバックアップしてください。
- Prefab sourceを持つ生成物・PrefabMode、未知のnative編集や置換対象Componentへの外部参照がある場合は切替を停止します。
- 非一様Socket／祖先scaleはnative基盤で非対応です。設定の自動修正は行いません。
- Unity内移行・保存再読込・両SDK buildは専用fixtureで確認済みです。VRC PCと実パッケージ欠落からの復旧は未確認です。
- インストーラーは公式配布元から取得します。依存のプレリリース版が選ばれる場合があるため、導入時にバージョンを確認してください。
